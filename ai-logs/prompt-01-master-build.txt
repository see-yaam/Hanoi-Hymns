  ## 2. THE PROJECT: "Zen Stones" — Recursive Soundscapes                       
  =====================================================================         
  Concept: A calm riverside at dusk. River stones sit on 3 flat rock platforms. 
  The Tower of Hanoi                                                            
  recursion moves the stones one by one; every move rings a singing-bowl-like   
  tone.                                                                         
  Key insight to highlight in the UI and README: the Hanoi move sequence (stone 
  1,2,1,3,1,2,1,4,...)                                                          
  is a fractal "ruler sequence" — the recursion literally composes a            
  self-similar rhythm.                                                          
                                                                                
  Judging weights (prioritize in this order!):                                  
  Relaxation/UX 35% > Musical quality 25% > Creative use of recursion 15% >     
  Visual design 10% > Interaction/usability 10% > Technical execution 5%.       
  => Calmness and sound quality matter more than technical complexity.          
                                                                                
  Stack: Vite + vanilla JavaScript (ES modules), Tone.js, HTML Canvas 2D. No    
  3D, no frameworks.                                                            
  Everything runs in the browser. Synthesize all sounds with Tone.js (no        
  external audio files)                                                         
  so there are no licensing issues and export works reliably.                   
                                                                                
  Suggested structure:                                                          
  src/recursion/hanoi.js   – pure recursive generator, yields {stone, from, to, 
  depth, index}                                                                 
  src/audio/engine.js      – instruments, scales, effects, ambience, scheduling 
  src/audio/export.js      – WAV export                                         
  src/visual/scene.js      – canvas scene, parallax layers, stone animation,    
  ripples                                                                       
  src/visual/stack.js      – live recursion call-stack visualization            
  src/ui/controls.js       – parameter panel, keyboard shortcuts, share link    
  src/main.js, index.html, style.css

  ### 3.1 Configurable recursive algorithm                                      
  - A real recursive Tower of Hanoi function (not iterative), exposed as a      
  generator of moves                                                            
    carrying recursion depth info.                                              
  - Parameters: stone count (3–8), start peg, target peg.                       
                                                                                
  ### 3.2 Interactive visualization ("2.5D" canvas)                             
  - Parallax layers: dusk sky gradient with slowly appearing stars, distant     
  hills, a gently                                                               
    flowing river, foreground grass. Subtle, slow motion everywhere — nothing   
  jerky.                                                                        
  - Stones: smooth rounded river-stone shapes with soft shading and shadows,    
  each stone a slightly                                                         
    different earthy tone. Moves are animated in a slow, soft arc with easing.  
  - When a stone lands: a water ripple expands and a soft glow pulses (synced   
  with its sound).                                                              
  - Recursion panel: a minimal, elegant live view of the call stack (e.g.       
  "hanoi(4, A→C)") with                                                         
    the current depth highlighted, plus a small display of the fractal ruler    
  sequence building up.                                                         
  - Progress indicator: move X / (2^n − 1).                                     
                                                                                
  ### 3.3 Procedural music from the recursion                                   
  Mapping (make it sound genuinely beautiful and calm):                         
  - Stone size -> pitch: largest stone = lowest note, smallest = highest,       
  mapped onto the chosen scale.                                                 
  - Destination peg -> instrument: peg A = singing bowl (FM/metal-like soft     
  bell with long decay),                                                        
    peg B = kalimba/marimba-like pluck, peg C = warm soft pad. This creates     
  natural harmony.                                                              
  - Recursion depth -> reverb wet / delay feedback (deeper calls = more         
  spacious echo),                                                               
    so the recursion is audible.                                                
  - Stereo pan follows the peg position (left / center / right).                
  - A quiet drone on the root note underneath everything.                       
  - Scales/moods: Pentatonic Major (Calm), Hirajoshi (Zen), Raga Bhupali        
  (Bangla Dusk),                                                                
    Dorian (Dreamy). Root note selectable.                                      
  - Seed: a seeded random generator adds tiny humanization (velocity,           
  micro-timing). Same seed +                                                    
    same settings must reproduce the exact same composition.                    
  - Ambience mixer synthesized in Tone.js: rain (filtered noise with random     
  droplets),                                                                    
    river (low filtered noise with slow modulation), wind (band-passed noise    
  with slow sweep).                                                             
  - Audio rules: soft attacks, generous reverb, master limiter, master level    
  around -10 dB,                                                                
    no harsh high frequencies, smooth fade-in/out. Audio starts only after a    
  user gesture.                                                                 
                                                                                
  ### 3.4 UI with controls and playback

  scale/mood, root note,
